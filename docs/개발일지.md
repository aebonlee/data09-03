## 결정과 이유

- **줄기는 언제나 하나.** `raf` 가 0 일 때만 새로 걸고, 매 장면 처음에 조건(멈춤·화면 밖·탭 숨김·다른 메뉴)을 다시 봐서 아니면 스스로 끝냅니다. 이벤트 연결은 처음 한 번만 하므로(머리 그림은 다시 그려지지 않는 고정 요소) 메뉴를 오가도 쌓이지 않습니다.
- **움직임 줄이기 설정이면 멈춘 채로 시작**합니다. 원래 그림(지게차가 요철 앞 평지에 선 모습) 그대로이고, 사용자가 「움직임 멈춤」을 풀 때만 움직입니다. 구간 누르기·마우스 올리기는 자리만 바꿔 한 장면을 그립니다.
- **넓은 화면은 한 바퀴를 글 상자 바로 오른쪽에서 시작**합니다. 글 뒤는 어둡게 덮여 있어 왼쪽 끝부터 달리면 몇 초 동안 아무것도 안 보이기 때문입니다(`lapStartX` — 글 상자 오른쪽 끝을 SVG 좌표로 바꿔 계산).
- **설명 5개를 한 칸에 겹쳐 둡니다**(grid 한 칸, 안 고른 것은 `visibility: hidden`). 가장 긴 설명 높이로 고정되어 구간을 눌러도 아래 내용이 밀리지 않습니다. 상태 줄의 구간 이름도 폭을 고정했습니다(요철 ↔ 경사로가 바뀔 때 뒤 글이 옆으로 밀리지 않게).
- **그림을 덮는 층이 마우스를 가로채지 않게** `.hero::before`·`.hero-inner` 에 `pointer-events: none`, 글 상자만 `auto`. 넓은 화면에서 그림이 글 층 아래(z-index -2)에 있어 이것이 없으면 마우스 올리기·구간 누르기가 안 됩니다.
- **첫 화면 그리기 전 바닥글 숨김(기존 결함 함께 고침).** 큰 엑셀 라이브러리(`vendor/xlsx`)를 읽는 동안 브라우저가 빈 화면을 먼저 그려, 바닥글이 보였다가 아래로 밀리는 레이아웃 이동(CLS 0.04~0.10)이 있었습니다. 이번 커밋 전 판(HEAD)에서도 같은 값이 나는 것을 확인했습니다. `app.js` 가 첫 화면을 그린 뒤 `html.app-ready` 를 붙이고, 그 전에는 바닥글을 `visibility: hidden` 으로 둡니다.

- **연료 단가는 사용자가 적습니다.** 도구 안에 가격을 정해 두지 않습니다(오피넷 자동 조회는 3단계, 공식 제공 방식 확인 필요). 단가는 월별·연료별로 저장하고, 단위(L/kg)·가격 출처·조회일을 함께 적어 기성 엑셀의 「연료 단가」 시트에 남깁니다. 단가가 빈 연료는 0원으로 계산하지 않고 「단가 없음」으로 표시합니다.
- **연료비 = 모델별 월 소모량 합계 × 단가, 원 단위 반올림.** 행마다 반올림해 더하면 끝전이 달라지므로 합계 소모량에 한 번만 곱합니다. 기성 총액은 모델·연료별로 반올림한 금액의 합입니다.
- **기성 월 기본값은 「이번 달보다 앞선 마지막 달」**입니다. 월말 기성은 지난달을 마감하는 일이기 때문입니다.
- **기성용 엑셀은 임시 양식**입니다(기성 요약·연료 단가·현황 데이터·입력값 검사 4개 시트). 실제 「일정 양식의 EXCEL」을 받으면 그 배치로 바꿉니다(기획서 5장 「MVP(양식 수령 후)」).
- **입력값 검사는 막지 않고 표시만** 합니다. 오류 행도 집계에 들어가되, 기성 화면에서 그 달 오류 수를 경고하고 기성 엑셀에 검사 결과 시트를 붙입니다. 행을 누르면 바로 고칠 수 있습니다. 못 읽은 원래 값(예: 「abc」)은 지우지 않고 고치는 창에 보여 줍니다.
- **누적값 역행은 같은 모델·호기끼리 일자순으로** 비교합니다(엑셀에 적힌 순서와 무관). 오늘 시작 아워미터가 전 일지 종료값보다 0.05시간 넘게 작으면 오류입니다.
- **대시보드 막대는 한 가지 색**(크기만 비교)으로 하고, 막대 옆에 숫자를 적고 마우스를 올리면 일지 수·기간이 보이게 했습니다. 월별 추이는 표(숫자 + 작은 막대)로 두어 색만으로 읽는 곳이 없습니다.
- **예시 데이터는 실제 데이터와 섞이지 않게** 했습니다. 예시 위에 실제 엑셀을 불러오면 예시는 지워지고, 예시가 있는 동안에는 화면 위에 「예시 데이터」 띠가 보이며 내려받는 파일 이름에도 「_예시데이터」가 붙습니다.
- **CSV 는 UTF-8 이 아니면 EUC-KR 로 다시 읽습니다.** 엑셀에서 「CSV 로 저장」하면 한글 윈도우에서 EUC-KR 로 저장되는 경우가 많기 때문입니다. 내보내는 CSV 에는 BOM 을 붙여 엑셀에서 한글이 깨지지 않게 했습니다.
- **스크립트를 ES module 이 아닌 일반 스크립트로** 불러옵니다. `index.html` 을 파일로 열면(file://) 브라우저가 module 스크립트를 막기 때문입니다. `logic.js` 는 Node 테스트에서도 같은 파일을 씁니다.
- AI 관련 기능(문제점 분류·메일 초안)은 기획서 8장에서 3단계라 이번에는 넣지 않았습니다.

## 가정

- 표준 열 14개와 열 이름(`시작 아워미터(h)` 등)은 원문 항목(시간·배터리소모율·충전량·문제점)과 기획서 5장을 바탕으로 정한 가정입니다. 특히 **호기**와 **시작/종료 아워미터**는 원문에 없고, 「누적값 역행」 검사와 운행시간 계산을 위해 넣었습니다.
- 한 행 = 일지 한 장. 같은 일자·모델·호기가 두 줄이면 「중복」 확인 표시만 합니다(교대 근무로 한 날 두 장일 수 있어 지우지 않음).
- 기성 월은 달력 기준(1일~말일)입니다. 마감 기준일이 따로 있는지 확인 필요.
- LPG 단위 기본값은 L 이며 화면에서 kg 으로 바꿀 수 있습니다. 소모량 칸에 적힌 수치의 단위와 같아야 합니다.
- 전동 모델은 충전량 합계만 보이고 전력비는 계산하지 않습니다(기성 대상 여부 확인 필요).
- 범위 검사 기준은 임시값입니다: 하루 운행시간 24시간 이하, 배터리소모율 0~100%, 음수 불가.
- 입력 누락일은 모델·호기별 첫 일지~마지막 일지 사이에서 일지가 없는 날이며, 기본으로 토·일을 뺍니다(시험 운영 요일 확인 필요). 휴무·정비일도 함께 잡힙니다.
- 운전자 빈 칸은 오류가 아닌 「확인」으로 둡니다.
