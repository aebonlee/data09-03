## 실행 방법

설치할 것이 없습니다. 서버·API 키도 쓰지 않고, 파일은 브라우저 밖으로 나가지 않습니다.

- **온라인**: https://aebonlee.github.io/data09-03/
- **로컬**: 이 폴더의 `index.html` 을 더블클릭해 크롬·엣지로 엽니다. 인터넷이 없어도 동작합니다(엑셀 라이브러리도 `vendor/` 에 들어 있습니다).
  - 간이 서버로 열어도 됩니다: 폴더에서 `python3 -m http.server 8000` → `http://localhost:8000`

처음 열면 데이터가 비어 있습니다.

1. **「예시 데이터 불러오기」** 를 누르면 가상의 3개 모델 일지(두 달 전 1일~어제, 평일)가 들어가고, 화면 위에 「예시 데이터」 안내 띠가 보입니다.
2. 실제 엑셀은 **「엑셀·CSV 불러오기」** → 「열 맞추기」에서 내 엑셀의 열을 표준 항목에 연결 → 불러오기. 모델별로 시트·파일을 나눠 쓰는 경우 시트 이름(또는 파일 이름)을 모델로 씁니다.
3. **「월간 기성」** 에서 그 달 평균 연료 단가(출처·조회일)를 직접 적으면 모델별 연료비가 계산되고, **기성용 엑셀**을 내려받습니다.
4. **「대시보드」** 에서 모델별 누적 운행시간, 월별 추이, 최근 문제점, 입력 누락일을 봅니다.

- 데이터는 **이 브라우저(localStorage)에만** 저장됩니다. 보관·이동은 「현황 엑셀 내보내기」로 합니다.
- 예시 파일(모두 가상 데이터): `samples/표준_현황엑셀_빈양식.xlsx`, `samples/예시데이터_표준현황.xlsx`·`.csv`, `samples/예시데이터_모델별엑셀.xlsx`(열 이름이 표준과 다른 모델별 시트 — 열 맞추기 시험용)
- 로직 테스트: `node test/logic.test.mjs` (의존성 없음)
- 예시 파일 다시 만들기: `node scripts/make-samples.js`

## 1단계 구현 범위

기획서 5장 기능 목록 기준입니다. 완료 = 이번 1단계 웹 도구에 들어감, 다음 단계 = 기획서 8장 2·3단계.

| 기능 (기획서 5장) | 상태 | 1단계에서 한 것 / 남은 것 |
|---|---|---|
| 표준 현황 엑셀 형식 | 완료(가정) | 14개 열(일자·모델·호기·시험 종류·운전자·시작/종료 아워미터·운행시간·배터리소모율·충전량·연료 종류·연료 소모량·문제점·사진 참조), 빈 양식 내려받기. 열 이름은 샘플 확인 후 확정 |
| 현황 엑셀 불러오기 | 완료 | xlsx·xls·csv, 여러 파일·여러 시트 한 번에, 머리행 자동 찾기, 열 맞추기(자동 추천 + 직접 선택, 연결 기억), 모델 열이 없으면 시트/파일 이름을 모델로, 추가/바꾸기 |
| 월간 기성 집계 | 완료 | 모델별 월 일지 수·운행 일수·운행시간, 연료 종류(경유·LPG)별 소모량, 전동 모델 충전량 합계 |
| 연료비 계산 | 완료 | 월별·연료별 평균 단가를 사용자가 입력(가격을 정해 두지 않음), 단위(L/kg)·가격 출처·조회일 기록, 단가 빈 연료는 표시만 |
| 기성용 엑셀 출력 | 일부(임시 양식) | 기성 요약·연료 단가·현황 데이터·입력값 검사 4개 시트. 실제 기성 양식 배치는 양식 수령 후 2단계 |
| 현황 대시보드 | 완료 | 모델별 누적 운행시간, 월별 추이, 최근 문제점 목록, 입력 누락일(토·일 제외 선택), 기간·모델 필터 |
| 입력값 검사 | 완료 | 빈 칸, 누적 아워미터 역행, 종료<시작, 범위 밖(하루 24h 초과·배터리 100% 초과·음수), 못 읽은 값, 운행시간·아워미터 불일치, 알 수 없는 연료, 중복. 행을 눌러 바로 고치기 |
| PDF 일지 자동 인식(OCR) | 다음 단계 | 2단계 — 일지 PDF 샘플 수령 후. 출력은 지금의 표준 현황 형식을 그대로 씁니다 |
| 양식 매핑 관리 | 다음 단계 | 2단계 (지금은 엑셀 열 맞추기만) |
| 문제점 심각도 분류·메일 초안 | 다음 단계 | 3단계 |
| 사진 연결 | 다음 단계 | 3단계 (지금은 「사진 참조」 칸에 파일명·위치만) |
| 알림 자동화(Make) | 다음 단계 | 3단계 |
| 연료 가격 자동 조회 | 다음 단계 | 3단계 (공식 제공 방식 확인 필요) |
