## 실행 방법

설치할 것이 없습니다. 서버·API 키도 쓰지 않고, 파일은 브라우저 밖으로 나가지 않습니다.

- **로컬**: 이 폴더의 `index.html` 을 더블클릭해 크롬·엣지로 엽니다. 인터넷이 없어도 동작합니다(엑셀 라이브러리도 `vendor/` 에 들어 있습니다).

처음 열면 데이터가 비어 있습니다. 「예시 데이터 불러오기」로 가상의 3개 모델(야간 일지·목표 도달 모델 포함)을 넣어 흐름을 볼 수 있습니다.

| 메뉴 | 하는 일 |
|---|---|
| **처음 화면** | 지게차 내구시험장(코스 배치도·요철·경사로·라바콘) 그림 위에 도구 이름과 바로가기, 업무 흐름 4단계 카드, 이 브라우저에 저장된 일지 수·사용 중 모델·최근 일지·문제점 일지 수, 보조 화면(현황 데이터·대시보드) |
| **1. 시험일지 입력** | TPR 양식과 같은 순서의 입력 화면 — 작성자(코드)·작성일(요일 자동, **일지에 적힌 요일과 대조** — 1/3 을 1/30 으로 읽으면 요일이 맞는 날로 고치기)·주/야/휴·날씨·모델/호기·충전·가동시간·Hour Meter(전 일지 값 불러오기, 금일 = 전일 + 가동), 시험 항목별 시간·회수, 배터리 구간별 시작/종료 %(방전·충전 합계), 문제점/조치내용 여러 줄, 일일 점검 ①~⑤ 유/무, 협조·개선 사항, 주유 기록(경유 L·**경유 결제 금액**·LPG kg 또는 통 수·요소수 L·**요소수 결제 금액**). 일지 사진·PDF 를 옆에 띄워 옮겨 적기(기본 — 외부로 보내지 않음), **AI로 옮겨 적기(선택, TPR 대외비라 하루 2장까지)**. 기성 마감일에는 **「마감 전 가입력(예상치)」**으로 저장했다가 가동 후 **「가동 후 확정 저장」**. 작성일 옆에 휴일 근무·마감일 표시. 「저장하고 다음 일지」는 주간 → 같은 날 야간으로 이어집니다. 문제점을 적어 저장하면 안내 띠가 뜨고, 담당자와 협의한 뒤 **「문제점 메일 정리」**로 문제점·사진 목록 초안을 만들어 직접 보냅니다(자동 발송 없음) |
| **2. 시험일지 정리** | 모델 정보(초기 아워미터·목표 가동시간·PG·과제번호·연료)와 일자별 정리표 — 누적 가동시간·누적 아워미터·누적 Ratio·경유/요소수 합계 자동 계산. 받은 정리 엑셀과 같은 배치로 내려받기(모델별·전체). 모델 목록을 **기간으로 나눠 보기**(이번 달·이번 기성 기간·직접 입력·전체 — 기본은 기간에 일지가 있는 모델만), 끝난 모델은 **「사용 종료」**로 목록에서 빼기 |
| **3. 주간 현황** | 매주 수요일 R&D 전체 보고용(기준일 기본값 = 가장 최근 수요일). 모델별 진행 시간(현 시험시간 / 목표시간 — 기본 1000h, 특화 1500h) 막대 그래프, 진행 표·예상 완료일(참고), 모델별 문제점, 설계담당자 메일 제목·본문 생성(복사·메일 프로그램 열기), 그래프 PNG/SVG 저장·인쇄, 문제점마다 **문제점 메일 정리**(받는 사람은 그때그때) |
| **4. 기성처리** | **기간 직접 입력** — 운전시간(월 단위)과 연료비(영수증 기준)의 시작일·종료일을 따로. **마감 준비** — 마감일(근무일 기준 월 말일, 공휴일 목록 제외) 자동 계산, 기성 기간 기본값 = 전달 마감일 다음 날 ~ 이달 마감일(1일부터 매일 청구서 초안이 채워짐), 체크리스트 8항목(빠진 근무일·오류·휴일 근무·단가·과제번호·마감일 가입력·확정), 공휴일 목록·**회사 휴무일**(휴가 기간·근로자의 날) 고치기, **가입력·확정 대조**(항목별 차이·기성금액 차이, 엑셀 시트). **운전시간 정산** — 기간·기종·주/야/휴별 금월·TPR·특화 시간, 과급(계약 고정 야간 19%·휴일 30% — 휴일은 날짜로: 토·일·공휴일)·단가 → 소계·기성금액, 5. 내구시험 현황. **연료비 정산** — 경유·요소수는 일지의 **카드 결제 금액** 합(단가 없음), LPG 는 사용량 × **그달 오피넷 월평균**(두 달이면 달별), LPG 15kg 통 수, 요소수 별도 청구 줄, 금액 빈 주입 알림. 받은 청구서 배치(결재란 직책·칸 합치기) + 운전시간은 기종별 상세 시트, 연료비는 「기종별 연료 주입 현황」·단가 시트 엑셀 |
| 현황 데이터 | 전체 일지 목록·입력값 검사·행 고치기, **엑셀·CSV 불러오기**(지금 쓰는 정리 엑셀을 넣으면 위쪽 모델명/호기·초기 아워미터·목표까지 읽음), 현황 엑셀·CSV 내보내기 |
| 대시보드 | 모델별 누적 운행시간, 월별 추이, 최근 문제점, 입력 누락일 |

- 데이터는 **이 브라우저(localStorage)에만** 저장됩니다. 보관·이동은 「현황 엑셀 내보내기」로 합니다.
- 예시 파일(모두 가상 데이터): `samples/예시데이터_시험일지정리.xlsx`(받은 정리 엑셀 배치 — 불러오기 시험용), `samples/표준_현황엑셀_빈양식.xlsx`, `samples/예시데이터_표준현황.xlsx`·`.csv`, `samples/예시데이터_모델별엑셀.xlsx`
- 로직 테스트: `node test/logic.test.mjs` (의존성 없음, 94개 — 사진 속 청구서 금액 24,901,176원·4,245,975원·4,441,660원과 정리표 누적 199.5h·266.5h 를 그대로 재현)
- 예시 파일 다시 만들기: `node scripts/make-samples.js`
- DB 스크립트 검증: `./scripts/sqltest/run.sh` (로컬 PostgreSQL 필요)

| 기능 | 상태 | 비고 |
|---|---|---|

| AI 반자동 읽기 | 완료 (2026-09-29, 오후 늦게 제한) | 선택 기능. TPR 은 대외비라 1장씩·하루 2장까지만(확인 표시 후 요청문 복사) |
| 기성 마감 준비·가입력/확정 대조·휴일 날짜 판정 | 완료 (2026-09-29 오후 늦게) | 공휴일 목록은 사용자가 고침(2026년 음력·대체공휴일 초안) |
| 시험일지 정리표·엑셀 | 완료 (2026-09-29) | |
| 정리 화면 모델 목록 기간 보기·사용 종료 | 완료 (2026-09-30) | 보이는 수 + 숨긴 수 = 전체. 누적은 기간과 상관없이 시험 시작부터 |
| 주간 현황·메일 본문·그래프 | 완료 (2026-09-29) | 자동 발송은 다음 단계(브라우저만으로는 예약 발송 불가) |
| 문제점 메일 정리 | 완료 (2026-09-30 바꿈) | 자동으로 띄우거나 보내지 않음 — 담당자와 협의 후 「문제점 메일 정리」로 초안을 만들어 직접 보냄 |
| 운전시간·연료비 기성 청구서 | 완료 (2026-09-29, 09-30 보강) | 기간은 직접 입력(운전시간 월 단위·연료비 영수증 기준 따로). 경유·요소수 = 주입 때 카드 결제 금액, LPG = 사용량 × 오피넷 월평균(달별). LPG·경유 대장은 스캔 첨부라 만들지 않음 |
| 처음 화면·다크블루 디자인 | 완료 (2026-09-30 오후) | 직접 그린 SVG(외부 이미지·로고 없음). 글자 대비 모두 4.5:1 이상(계산값은 개발일지) |
| 날짜 ↔ 요일 대조·회사 휴무일 | 완료 (2026-09-30) | 손글씨 날짜(1/3 ↔ 1/30)를 일지에 적힌 요일로 확인, 휴가·근로자의 날을 일반 달력에 더함 |
